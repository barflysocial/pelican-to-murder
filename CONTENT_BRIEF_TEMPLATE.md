# Content Brief Template — Forensics / Interrogation / Timeline / Deduction

## Mystery title

## Difficulty
Easy / Medium / Hard

## Venue fiction
Briefly describe the event, victim, and reason the case begins.

## Culprit
Name, motive, method, access, and proof.

## Forensics evidence
Processed reports from recovered evidence. Use these categories as needed:

- Recovered Phone Analysis
- Message Extraction Report
- Financial Records Review
- Document / Metadata Review
- Browser History Review
- Photo / Video Review
- Security Footage Review
- Physical Evidence Report

Each forensic item should include:

- title
- unlock timing
- story time if relevant
- what the report proves
- how it conflicts with or supports an interrogation claim

## Interrogation evidence
Statements from suspects/witnesses only. Each person can provide:

- Alibi
- Timing
- What They Noticed

Statements should not confess directly. They should give players something to compare against Forensics and Timeline.

## Timeline events
Only actual case events in order. No system messages.

## Deduction questions
Five round deduction questions plus five final accusation questions.

Do not use old player-facing labels such as Crime Scene, Checkpoint, Case Feed, Latest Case Updates, Send to Forensics, Review Recap, or Return to App.
