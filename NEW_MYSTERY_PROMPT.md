# New Mystery Prompt — Barfly Social Mystery Engine

Use this engine structure only:

- Forensics
- Interrogation
- Timeline
- Deduction

The crime scene is already processed before the player begins. Do not create a separate Crime Scene button or a manual Send to Forensics step.

## Forensics
Use Forensics for processed evidence recovered from the scene:

- phone records
- message extractions
- financial records / bank statements
- documents and metadata
- browser history
- photos / video / security footage
- physical evidence reports

## Interrogation
Use Interrogation only for people-based evidence:

- suspect statements
- witness statements
- alibis
- timing claims
- motive / relationship answers
- what they noticed or deny

## Timeline
Use Timeline only for actual case events in order. Do not include system messages, chapter-open messages, difficulty-loaded messages, or host/debug text.

## Deduction
Use Deduction for all round deduction questions and the final accusation. Deduction questions should only cover evidence available by that point in the game.

Keep the player dashboard clean. Do not add old app buttons like Phone, Messages, Bank, Photos, Files, Browser, Crime Scene, or Checkpoint.
