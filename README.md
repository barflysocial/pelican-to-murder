# The Velvet Cypress Mysteries

Built from the Barfly Mystery Engine Template. This clean package includes three playable mysteries for a fictional upscale Baton Rouge supper-club style venue inspired by candlelit fine dining, lounge energy, private reservations, elevated service, dress-code drama, and luxury table presentation.

## Included mysteries

1. **The Candlelit Cut** — Easy
2. **Smoke Over Table Twelve** — Medium
3. **The Midnight Reservation** — Hard

Each mystery includes a unique victim, culprit, evidence set, forensic findings, timeline logic, method, motive, outcome, RSVP excerpt, and 9:16 title graphic.

## Engine features retained

- Host dashboard
- RSVP / My RSVP / Play Now
- Free and paid event handling
- 5-digit numeric check-in codes
- Waiting room with server-time countdown
- Waiting-room tutorial
- Case Feed
- Crime Scene search
- Physical evidence discovery over time
- Send to Forensics with countdowns
- Interrogation prompts for witnesses and suspects
- Timeline building
- Detective Notes with autosave
- Detective Decisions
- Final Accusation
- Case Closed screen
- Badge scoring
- Sponsor popup manager

## Render

Build command:

```bash
npm install
```

Start command:

```bash
npm start
```
